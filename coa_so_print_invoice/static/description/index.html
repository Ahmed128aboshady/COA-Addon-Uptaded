COA Sale Order - Direct Invoice Print

Print sale order invoices directly from the SO with one click.

A certified premium Odoo extension developed by Community of Accountants (COA).

Price: $19 USD License: OPL-1 By: COA Egypt

Key Features & Capabilities

Direct Print

Adds a "Print Invoice" button directly on the Sale Order header.

Browser Dialog

Opens the invoice PDF and launches the browser print dialog instantly.

Access Bypass

Enables salespeople to print invoices even without accounting permissions.

How It Works

  1. Install the module from the Odoo Apps list.
  2. Configure relevant rules or parameters under the Settings menu.
  3. Use the newly added fields, validations, and workflows on documents.
  4. Verify outputs and check generated logs or reports.
