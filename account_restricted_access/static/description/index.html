Overview

Functional Description

Account Restricted Access ========================== يسمح هذا الموديول بتحديد قائمة حسابات (Many2many) لكل مستخدم من خلال بطاقة المستخدم (Users). المستخدم المنتمي لمجموعة "محاسب مقيّد الصلاحية" لن يرى ولن يستطيع الوصول إلا إلى: - حركة القيود (Journal Items / account.move.line) الخاصة بالحسابات المسموح بها فقط - دفتر الأستاذ العام (General Ledger) محدود بهذه الحسابات - شجرة الحسابات (Chart of Accounts) محدودة بهذه الحسابات فقط تم تطويره بواسطة Community of Accountants - COA Odoo Silver Partner
