# Arfad Custom Payslip Report (`arfad_payslip_report`)

## 📌 الوصف العام (Overview)
Custom Bilingual Payslip Report Layout for Arfad

### التفاصيل الوظيفية:

        Replaces the default Odoo payslip PDF with a custom bilingual
        (Arabic / English) layout matching Arfad company design.
