Automated Account Merge Engine

COA Account Merge simplifies accounting cleanup by allowing financial managers to combine duplicate accounts into a single target account cleanly.

1-Click Account Selection

Select source accounts to be merged and specify the destination master account.

Preserves Financial Ledgers

Automatically re-links all posted and draft journal items to the destination account.

Detailed Functional Breakdown

Provides a user-friendly wizard in Odoo Accounting to select source accounts and destination target account with immediate validation checks.
Re-points all existing account.move.line entries from source accounts to the destination account seamlessly across all journals.
Logs all merge actions in digital audit trails and removes empty source accounts cleanly to prevent future duplicate postings.
