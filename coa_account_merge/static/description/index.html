SYSTEM CAPABILITIES

Functional Breakdown & System Architecture

1. Account Merge Wizard

Provides a user-friendly wizard in Odoo Accounting to select source accounts and destination target account with immediate validation checks.

2. Move Line Reassignment

Re-points all existing account.move.line entries from source accounts to the destination account seamlessly across all journals.

3. Audit Log & Safety

Logs all merge actions in digital audit trails and removes empty source accounts cleanly to prevent future duplicate postings.
