Warehouse Location & Operation Restriction

by Community of Accountants

Limit user access to specific warehouses, stock locations, and transfer picking operation types. Prevent stock information leakage and unauthorized stock validations outside designated work zones.

Features recursive matching for nested location structures, direct integration into native res.users models, and strict ORM-level query filtering ensuring complete data security and rapid report loading.

Granular Security for Multi-Warehouse Settings

Odoo default warehouse settings grant sweeping validation clearance across all inventory routes. This module implements a robust security layer directly inside user forms to guarantee strict separation of duty.

Why Choose Location & Operation Restriction

Secure, high-performance database-layer filters built for inventory control and internal audits.

Recursive Location Paths

Assigning a parent stock location automatically clears all child shelves, rows, and bins. Simplify mapping configuration.

ORM-Level Fast Querying

Queries are filtered at the search hook database layer. Guarantees zero lag on reports or dashboard inventories.

Picking Action Constraints

Restrict warehouse staff to specific operation categories. Clear user access for Receipts but restrict Deliveries or Transfers.

Validation Interceptor Guard

Stops picking confirmations and stock modifications from external API connections if locations involve restricted zones.

Complete Inventory Security Features

Engineered specifically to satisfy strict internal corporate stock control audits.

Warehouse Access Control

Filters Odoo warehouse records at the search query level. Restricted users can only select allowed warehouses.

Recursive Child Authorization

Clearing a parent location automatically grants permissions to all child bins, shelves, and sub-locations recursively.

Operation Type Constraints

Scope user operations dynamically. Limit operators to Receipts only, preventing access to Deliveries or Transfers.

Active Validation Interceptor

Strict backend write guards intercept picker submissions. Prevents save or validation actions involving restricted locations.

Real-time Stock Levels Masking

Automatically filters standard stock quant models. Restricted staff only see quantities present in allowed stock zones.

Odoo 19 Native _search Hook

Rebuilt utilizing v19 ORM search hook overrides. Avoids performance lag, admin loop bypasses, and security gaps.
