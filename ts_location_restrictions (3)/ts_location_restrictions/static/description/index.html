Security & Enforcement Workflow

Multi-layer verification system to prevent unauthorized stock transactions.

1

Configure User

Toggle restrictions on the user card. Select allowed Warehouses, Locations, and Operation Types.

2

Filter Stock Views

Odoo automatically applies `_search()` filters, keeping unauthorized warehouses, transfer pickings, and stock quants invisible.

3

Enforce Hierarchy

Allowed locations automatically grant access to child structures recursively (e.g., Row A covers Shelf A1, Shelf A2).

4

Validation Guard

If a user attempts validation via API or workaround, the backend guard blocks it, displaying a clear access error message.

High-performance Governance for Multi-Warehouse Setups

Standard Odoo permits generic inventory users to access all locations and validate any picking. For companies with multiple branches or segmented staff, this leads to inventory discrepancies and security leaks. This module solves these governance flaws.

  • No Database Bloat: Clean _search hooks run directly at the database query layer.
  • Recursive Permissions: Add parent locations once; children are covered automatically.
  • Operation Type Restraints: Limit staff to only perform Receipts, Deliveries, or Internal moves.
  • Administrative Guards: Strict code checks prevent administrative loop locks (e.g. self.env.su checks).
  • Zero UI Clutter: Configured seamlessly inside the native Odoo user settings.
