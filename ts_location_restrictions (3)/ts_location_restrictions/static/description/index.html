Warehouse Access Security

Granular Location Restrictions

Restrict inventory staff to authorized warehouses, locations, and picking operation types to prevent stock discrepancies.

Key Deliverables

Standard Odoo permits generic inventory operators to access all physical locations and validate any stock picking. This lack of boundaries leads to stock allocation mistakes and internal compliance issues. This module secures your locations by mapping restrictions directly to user cards.

  • Recursive location permission (nested sub-shelves inherit parent access).
  • Warehouse access scopes (hides unauthorized warehouse records).
  • Picking operation type restrictions (restricts receipts, internal transfers, etc.).
  • Access validation interceptor (blocks unauthorized picking confirmations).

Core Positioning

Features provide configuration, but recursive database security guarantees daily operational audit safety.

  • Applies database-layer query filters.
  • Prevents administrative loop locks.
  • Fully optimized for Odoo 19 _search() hooks.

1 Recursive Permissions

Assign parent stock locations once. The module automatically grants query access to all nested child shelves and sub-bins.

2 Operation Type Limits

Limit users to execute specific pickings. Restrict access so staff can only process Receipts, Deliveries, or Internal moves.

3 Strict Validation Guard

Prevents validation workarounds. Blocks picking confirmations with a clean access denied warning box if locations are restricted.

Frequently Asked Questions

Q: How does the recursive check handle sub-locations?

A: When checking allowed locations, the module checks if the target location or any of its parents match the allowed list. This recursively covers all sub-shelves, rows, and bins automatically.

Q: Can I exempt specific warehouse managers from these rules?

A: Yes. You can simply disable the 'Enable Location Restriction' flag on their user profile. They will have standard Odoo inventory permissions.

Q: Does this filter stock inventory reports and quantity on hand?

A: Yes. The search hooks filter the stock.quant model, ensuring restricted users only see quantities on hand for allowed locations.
