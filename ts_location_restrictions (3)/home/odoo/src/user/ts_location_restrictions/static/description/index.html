Business Solution Overview

Granular warehouse security and access controls mapped to Odoo Inventory profiles.

The Business Challenge

Standard Odoo permits generic inventory users to access all physical warehouses, stock locations, and execute any picking operation type. For companies with multiple branches or segmented operations, this lack of boundary controls leads to stock level discrepancies, unauthorized internal moves, and compliance audit failures.

Our Solution

This module introduces user-level restrictions directly into Odoo's security model. Managers restrict users to specific warehouses, allowed stock locations, and operation types. It automatically applies recursive logic (inheriting all nested child locations) and features database-layer search hooks to filter inventory views, stock quants, and validation commands securely.

Key Capabilities

Functional details of the warehouse security extension.

Warehouse Level Access Control

Limits user views to allowed warehouses only. Restricts picking creation and warehouse selections on res.users cards.

Recursive Location Permission

Enforces location hierarchies automatically. Specifying parent locations grants automatic clearance to all child locations recursively.

Database-Layer Search Filters

Applies filters directly to database queries. Prevents restricted users from viewing unauthorized stock levels or picking lines.

Access Enforcement Workflow

Processing boundaries for restricted operations.

1
Admin Configuration

The manager accesses the User form, enables the restriction flag, and assigns allowed Warehouses, Locations, and Operations.

2
Search & View Filtering

Odoo applies ORM search filters dynamically, hiding unauthorized records from all dashboard list views and search bars.

3
Recursive Check

The backend queries access paths recursively. Granting permission to a parent folder automatically verifies access to its sub-shelves.

4
Operation Validation Guard

If a restricted user executes a transfer validation, the backend interceptor blocks the command and displays an access error banner.
