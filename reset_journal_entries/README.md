# Reset Journal Entries (`reset_journal_entries`)

## 📌 الوصف العام (Overview)
Using this module, multiple journal entries can be set as
    draft, canceled, and posted in invoicing.

### التفاصيل الوظيفية:
This module allows users to post multiple journal entries
    in draft state to posted, reset posted entries back to draft state, and
    cancel entries.
